# ChessSchool

Платформа для шахматных школ на базе idchess: учёт партий и рейтинга учеников, прогресс для
родителей по ссылке и **онлайн-игра в реальном времени** с прицелом на масштаб (десятки/сотни
тысяч одновременных партий). Бэкенд на ASP.NET (.NET 10), фронт — Blazor (SSR для SEO),
оркестрация — .NET Aspire. Подробное ТЗ: [docs/TЗ_ChessSchool_Platform.md](docs/T%D0%97_ChessSchool_Platform.md).

## Архитектура (сервисы Aspire)

| Проект | Роль |
|---|---|
| `ChessSchool.AppHost` | Оркестратор Aspire — запускает и связывает все сервисы |
| `ChessSchool.Auth` | Отдельный сервис авторизации (IdP): OIDC-discovery, JWT (RS256), JWKS — переиспользуемый, как Google Auth |
| `ChessSchool.ApiService` | Доменный API: школы, ученики, рейтинг (Elo), архив партий, шаринг профиля |
| `ChessSchool.GameServer` | Онлайн-игра: **Orleans** (грейн на партию) + **SignalR** (транспорт) + матчмейкинг |
| `ChessSchool.Web` | Blazor Web App: ЛК школы, профиль ученика, публичная страница для родителя, онлайн-доска |
| `ChessSchool.ServiceDefaults` | Общие health-checks, OpenTelemetry, service discovery |
| `ChessSchool.Contracts` | Общие DTO и контракты SignalR |
| `ChessSchool.Tests` | Юнит- и интеграционные тесты |

### Масштабирование онлайн-игры
- Каждая партия — Orleans-**грейн** (однопоточный доступ к состоянию → нет гонок без локов).
- Завершённые партии деактивируются (в RAM только активные).
- Транспортный ярус (SignalR) и ярус состояния (Orleans-силосы) масштабируются независимо.
- Локально: Orleans `localhost`-кластер + SignalR in-proc + PostgreSQL (контейнер от Aspire).
- Прод: кластеризация Orleans и SignalR backplane → Redis; персист → тот же PostgreSQL (managed).
  dev и прод на одном провайдере БД; схема — через EF-миграции.

## Запуск локально

Требуются .NET 10 SDK и контейнер-рантайм (**Docker/Podman**) — Aspire поднимает контейнер PostgreSQL.

```bash
dotnet run --project ChessSchool.AppHost
```

Откроется дашборд Aspire. Веб-приложение (`webfrontend`) — точка входа:
- `/` — лендинг
- `/school` — ЛК школы (таблица учеников, добавление, кнопка «ссылка родителю»)
- `/students/{id}` — профиль ученика с графиком рейтинга
- `/p/{token}` — публичный профиль для родителя (read-only)
- `/attribution` — очередь атрибуции тренировочных партий
- `/play` — онлайн-партия (войдите/зарегистрируйтесь, затем «Найти соперника»;
  для демо откройте две вкладки с разными аккаунтами)

## Тесты и анализатор

```bash
dotnet test            # юнит + интеграционные (вкл. полный запуск AppHost)
dotnet format          # анализатор стиля/кода
```
