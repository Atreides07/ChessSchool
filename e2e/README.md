# E2E смоук-тесты (Playwright)

Браузерные смоук-тесты против **уже запущенного** приложения. Ловят UI/JS/enhanced-navigation
баги, которые `dotnet test` и юниты не видят (например, грабли #12/#13 — онлайн-доски трансляции,
не исполнявшийся при enhanced-навигации скрипт).

Это **не часть `dotnet test`** — отдельный Node-проект, гоняется по необходимости.

## Запуск

1. Подними приложение: `dotnet run --project ChessSchool.AppHost` (нужен Docker).
2. Возьми внешний URL Arena из дашборда Aspire (обычно `https://localhost:7167`).
3. Установка и запуск:

```bash
cd e2e
npm install          # Chromium берётся из кэша ~/Library/Caches/ms-playwright
npm test             # или: ARENA_URL=https://localhost:7167 npm test
```

`ARENA_URL` переопределяет базовый адрес (по умолчанию `https://localhost:7167`).
Дев-сертификат принимается (`ignoreHTTPSErrors`).

## Что проверяется

- `broadcasts.spec.js` — главная и список трансляций грузятся без ошибок консоли; при переходе со
  списка на трансляцию **онлайн-доски отрисовываются** (не «висят» на «Загружаем доски…»), клик по
  доске открывает оверлей с навигацией по ходам.

Тест с досками пропускается (`skip`), если в каталоге нет трансляции с live-PGN — добавь её в админке
(`/admin/broadcasts/discover` → «Найти популярные» → «Добавить»), затем сделай видимой в списке трансляций.
